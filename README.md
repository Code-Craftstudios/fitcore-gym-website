# FITCORE Gym Website

Vanilla HTML5, CSS3 and JavaScript. No frameworks or build step.

## Run
Open `index.html`, or serve the folder: `python3 -m http.server 8000`

## Images
Photos are optional. Every image slot has a dark gradient fallback, so nothing breaks if a file is missing.
Drop files into these names to replace the placeholders:
- `assets/images/`: hero.jpg, about.jpg, cta.jpg, strength.jpg, personal.jpg, weight-loss.jpg, muscle.jpg, functional.jpg, hiit.jpg
- `assets/equipment/`: squat-rack.png, cable-machine.png, leg-press.png, smith-machine.png, bench-press.png, dumbbells.png, treadmill.png, functional-trainer.png
Text content for programs and equipment lives in the arrays at the top of `js/script.js`.
